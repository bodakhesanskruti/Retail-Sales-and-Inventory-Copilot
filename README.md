# Retail-Sales-and-Inventory-Copilot
AI-powered retail dashboard for sales analysis, inventory monitoring, stock-out prediction, sales trends, store performance, and data-driven recommendations with an AI Copilot.

## Features
- Total sales and revenue analysis
- Inventory status monitoring
- Stock-out prediction
- Non-moving stock detection
- Sales spike and drop detection
- Product-level sales trends
- Store performance comparison
- Today's important alerts
- AI Copilot for natural-language questions
- Data-backed recommendations

## Technology Stack

### Frontend
- React
- CSS
### Backend
- Python
- FastAPI
- Pandas
### Data
- CSV datasets
